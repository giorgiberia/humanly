## Humanly — human access and control

This project follows the Humanly standard. For changes affecting core user workflows, AI agent behavior, permissions, approvals, history, export, or deletion:

1. Read `HUMANLY.md` and follow its declared standard version, scope, and level. If it is missing, flag that and avoid claiming a verified level.
2. Use the `humanly` skill when available; otherwise follow the project's Humanly requirements.
3. Keep core tasks usable without an agent; preserve accessible, discoverable manual controls.
4. Keep agent status and outcomes visible; respect approvals, cancellation, and data controls according to the declared level.
5. Verify affected flows and report gaps. Never silently weaken a declared Humanly level or mark untested controls as passing.

Avoid unrelated audits for changes that don't affect these concerns.
